# Event Hub

Event Hub - это веб-приложение для организации и посещения мероприятий по интересам. Платформа заточена под структурированные события (прогулки, клубы, спорт) и прозрачную систему рейтингов, где участники могут оценивать организаторов после завершения событий.

Бэкенд написан на Spring Boot (REST API) с простым клиентом. Все упаковано в Docker для быстрого развертывания.

## Функциональные возможности

* **Аутентификация**: Регистрация и логин через JWT. Пароли хешируются через BCrypt. Пока реализована только роль участника (Participant).
* **Управление событиями**: Создание, редактирование и удаление событий. При отмене события все активные билеты автоматически аннулируются.
* **Каталог**: Поиск и фильтрация по типу, цене, датам и ключевым словам, есть пагинация.
* **Билеты**: Запись на мероприятия, генерация уникальных номеров билетов. Организатор может смотреть список участников.
* **Профили**: Просмотр чужих профилей, редактирование своего, просмотр статистики.
* **Отзывы**: Оставить отзыв можно только после завершения события. Рейтинг организатора пересчитывается автоматически.
* **Документация**: Интерактивная документация API через Swagger UI.

## Стек технологий

**Backend:**
* Java 24
* Spring Boot 4 (Web, Data JPA, Security, Validation)
* Hibernate / JPA
* PostgreSQL
* MapStruct (маппинг сущностей и DTO)
* JJWT (токены)
* Lombok

**Инфраструктура:**
* Docker, Docker Compose
* Gradle
* Springdoc OpenAPI

**Frontend:**
* JavaScript (ES6+), HTML5, CSS3

## Архитектура

Код разбит по модулям (Package by Feature):
* `auth` - пользователи и безопасность.
* `events` - события и каталог.
* `profile` - профили пользователей.
* `registration` - билеты и регистрация.
* `review` - отзывы и рейтинги.
* `common` - обработка ошибок, DTO, утилиты.

## Запуск проекта (Docker)

Понадобится установленный Docker Desktop.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/MeTaLdiCODING/event_hab.git
   cd event_hab
   ```

2. Запустите сборку и старт контейнеров в фоновом режиме:
   ```bash
   docker compose up --build -d
   ```

3. Проект будет доступен по адресам:
   * API и Swagger UI: `http://localhost:8080`
   * PostgreSQL: `localhost:5432`

Остановить контейнеры: `docker compose down`.

## Локальный запуск

1. Поднимите базу данных:
   ```bash
   docker compose up -d postgres
   ```

2. Запустите приложение через IDE (класс `HabApplication`) или в терминале:
   ```bash
   ./gradlew bootRun
   ```

## Документация API

Ссылка на Swagger UI (после запуска проекта):
`http://localhost:8080/swagger-ui/index.html`

Чтобы тестировать защищенные ручки, получите JWT через `POST /login` и вставьте его в кнопку `Authorize`.

## Конфигурация

БД и JWT настраиваются через переменные окружения в файле `docker-compose.yml`. Для реального сервера значения по умолчанию нужно поменять.

| Переменная | Описание |
| :--- | :--- |
| `SPRING_DATASOURCE_URL` | JDBC URL для подключения к базе данных |
| `SPRING_DATASOURCE_USERNAME` | Имя пользователя БД |
| `SPRING_DATASOURCE_PASSWORD` | Пароль пользователя БД |
| `JWT_SECRET` | Секретный ключ для подписи JWT-токенов |
