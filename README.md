# Event Hub

Event Hub — веб-приложение для организации и посещения мероприятий по интересам. Платформа фокусируется на структурированных событиях (прогулки, клубы, спорт) и прозрачной системе рейтингов, которая позволяет участникам оценивать организаторов после завершения событий.

Проект представляет собой REST API на базе Spring Boot с клиентской частью, полностью контейнеризированный для быстрого развертывания.

## Функциональные возможности

* **Аутентификация**: Регистрация и вход с использованием JWT, безопасное хеширование паролей (BCrypt), базовая ролевая модель (Participant).
* **Управление событиями**: Создание, редактирование, удаление событий. Отмена события автоматически переводит все активные билеты в статус отмененных.
* **Каталог**: Фильтрация и поиск по типу, цене, датам и ключевым словам с поддержкой пагинации.
* **Билеты**: Запись на мероприятия, генерация уникальных номеров билетов, просмотр списка участников для организаторов.
* **Профили**: Просмотр публичных профилей, редактирование личных данных, просмотр статистики.
* **Отзывы**: Оставление отзывов после завершения событий, автоматический пересчет рейтинга организатора.
* **Документация**: Интерактивная документация API через Swagger UI.

## Технологический стек

**Backend:**
* Java 24
* Spring Boot 4 (Web, Data JPA, Security, Validation)
* Hibernate / JPA
* PostgreSQL
* MapStruct (маппинг Entity и DTO)
* JJWT (работа с токенами)
* Lombok

**Инфраструктура:**
* Docker, Docker Compose
* Gradle
* Springdoc OpenAPI

**Frontend:**
* JavaScript (ES6+), HTML5, CSS3

## Архитектура

Проект использует модульную структуру (Package by Feature). Основные модули:
* `auth` — управление пользователями и безопасность (JWT).
* `events` — логика работы с событиями.
* `profile` — управление профилями.
* `registration` — билеты и запись на события.
* `review` — система отзывов и рейтингов.
* `common` — глобальная обработка исключений, общие DTO и утилиты.

## Запуск проекта (Docker)

Для запуска требуется установленный Docker Desktop.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/MeTaLdiCODING/event_hab.git
   cd event_hab
   ```

2. Запустите сборку и старт контейнеров в фоновом режиме:
   ```bash
   docker compose up --build -d
   ```

3. Сервисы будут доступны по адресам:
   * API и Swagger UI: `http://localhost:8080`
   * PostgreSQL: `localhost:5432`

Для остановки контейнеров используйте команду `docker compose down`.

## Локальный запуск (для разработки)

1. Поднимите базу данных:
   ```bash
   docker compose up -d postgres
   ```

2. Запустите приложение через IDE (класс `HabApplication`) или командой:
   ```bash
   ./gradlew bootRun
   ```

## Документация API

После запуска приложения интерактивная документация доступна по адресу:
`http://localhost:8080/swagger-ui/index.html`

Для тестирования защищенных эндпоинтов получите JWT через `POST /login` и вставьте его в кнопку `Authorize` в интерфейсе Swagger.

## Конфигурация

Параметры подключения к базе данных и секретный ключ для JWT задаются через переменные окружения в файле `docker-compose.yml`. В production-окружении значения по умолчанию должны быть изменены.

| Переменная | Описание |
| :--- | :--- |
| `SPRING_DATASOURCE_URL` | JDBC URL для подключения к базе данных |
| `SPRING_DATASOURCE_USERNAME` | Имя пользователя БД |
| `SPRING_DATASOURCE_PASSWORD` | Пароль пользователя БД |
| `JWT_SECRET` | Секретный ключ для подписи JWT-токенов |
